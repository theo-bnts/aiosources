# Contributing

Bug reports, usability feedback, documentation improvements and reviewed fixes are welcome.

- Explain what you expected, what happened and which version you used. Include minimal reproduction steps and screenshots when useful.
- Remove personal data, passwords, API keys, installation links and private announce URLs from every report.
- Do not submit real source definitions, content-site directories, production captures or database dumps. Examples and tests must use synthetic data and fictitious addresses.
- Keep changes focused, consistent with the existing interface and covered by appropriate checks. Describe the user-visible behavior and how it was verified in your pull request.
- Preserve copyright, attribution and third-party license notices when reusing code or assets.

Report vulnerabilities through the [private security process](SECURITY.md), not public issues. Community help on [Discord](https://discord.gg/h3sja5XN8b) is in French only.
